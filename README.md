# Loan Default Probability Prediction (ML BD Elective)

Predicting Lending Club charge-off probability and comparing XGBoost, Keras, PyTorch+fastai, PyTorch+TabNet, and PyTorch+Lightning Flash.

## Structure
- notebooks/: EDA and one notebook per framework
- src/: shared config, data loading and preprocessing, metrics
- reports/: report and figures
- extras/: optional PySpark work on the full dataset
